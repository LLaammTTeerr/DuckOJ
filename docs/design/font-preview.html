DuckOJ — monospace candidates

Every family below ships a vietnamese subset on Google Fonts and has a Nerd Font patched build (v3.5.0). Each card renders the same five things: Vietnamese with heavy diacritics, a dense problem-list row, box-drawing chrome, a code sample, and the characters that most often collide in a monospace face — 0O il1 {}[]() <>.

What to look for. Vietnamese stacked diacritics (ế ộ ữ ặ) should not clip or crowd the line above. Digits should be unmistakable at 13px in the table. 0 vs O and l vs 1 vs I should be instantly separable — a judge shows problem codes and hashes constantly.

Not shown: the Nerd Font icon glyphs. Those need a self-hosted patched build, which is a separate decision — a full patched font is 2–8 MB, subset to the icons actually used it is roughly 20–40 KB.
