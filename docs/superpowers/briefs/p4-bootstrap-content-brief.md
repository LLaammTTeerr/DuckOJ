## 2. Five demo problems in Polygon layout
- Under `content/problems/<code>/` produce Polygon-shaped problem
  directories that `scripts/polygon-import.ts` accepts (read
  `packages/polygon-import/src` and its test fixtures for the exact expected
  layout: `problem.xml`, `tests/`, statement, checker). Problems, classic
  provincial-olympiad style, statements in Vietnamese with an English
  section too (D10), difficulty ascending:
  1. `tong-hai-so` — A+B (checker `wcmp`-style standard compare).
  2. `so-nguyen-to` — count primes ≤ N (N ≤ 10^7), sieve.
  3. `day-con-tang` — longest increasing subsequence, N ≤ 10^5.
  4. `duong-di-ngan-nhat` — Dijkstra on N ≤ 10^5, M ≤ 2·10^5.
  5. `cay-khung-nho-nhat` — Kruskal MST.
  Each: a model C++ solution, a Python generator producing ≥10 tests with
  per-test expected outputs generated by the model solution (commit the
  tests, they are small), 2 samples, batches/subtasks encoded the way
  polygon-import expects points.
- `content/README.md`: the one command sequence to import all five into a
  running stack (`polygon:import` → `package:build` → upload — reuse the
  existing scripts; verify their CLI flags by reading them).
- Prove it: run `polygon:import` on each directory locally to a temp dest
  and paste the plan output; run each model solution on its samples.
